# Аналитика e-commerce и дизайн экспериментов на данных маркетплейса Olist

Комплексный продуктовый анализ транзакционных и операционных данных e-commerce платформы на Python (SQL + SciPy). Очистил метрики от аномалий, проверил бизнес-гипотезы и рассчитал параметры А/Б-теста.

## 📁 Структура репозитория:
* `1_Statis.ipynb` — расчет ЦПТ, биномиального закона и дизайн А/Б-теста [12.1].
* `2_hypo_correl.ipynb` — проверка стат-значимости (Манн-Уитни) и корреляционный анализ [12.1].


### 1. Фильтрация выбросов (IQR)
* **Проблема:** Суммы чеков имели сильную асимметрию, максимальный чек — 13 664 (std = 217.49).
* **Решение:** Применил метод IQR, отсек экстремальный 1% аномалий по верхней границе **344.41** [12.1].
* **Итог:** Шум (std) снизился в 3 раза (до 72.78). Истинный средний чек массового сегмента составил **110.06** (медиана — 92.20).

### 2. Проверка гипотез (Сравнение сегментов по способам оплаты)
* **Задача:** Проверить, правда ли, что платящие картами тратят больше тех, кто платит квитанциями (Boleto).
* **Решение:** Из-за ненормального распределения применил критерий **Манна-Уитни** [12.1].
* **Итог:** Разница высоко значима (p-value: 3.77e-47) [12.1]. Группа "Карты" (медиана 97.87) тратит больше группы "Квитанции" (87.525) на ~11%.

### 3. Дизайн эксперимента (Sample Size)
* **Задача:** Рассчитать объем выборки для маркетинговой акции с ожидаемым эффектом MDE = 5.
* **Решение:** Использовал функцию `tt_ind_solve_power`
* **Итог:** Необходимый объем выборки — **3 327 пользователей на одну группу**

### 4. Теория вероятностей (ЦПТ и Бернулли)
* **ЦПТ:** На основе бутстрапа (1000 подвыборок) экспериментально доказал действие Центральной Предельной Теоремы — средние значения чеков выстроились в идеальное нормальное распределение Гаусса вокруг отметки 110.
* **Биномиальное распределение:** Базовая конверсия заказов в отзывы составила p = 99.23% (99 224 отзыва на 99 992 заказа). По формуле Бернулли через `.pmf()` рассчитал, что вероятность получить идеальные 100 отзывов из 100 новых заказов составляет **46.3%**.

### 5. Факторный анализ удовлетворенности (CSAT Drivers)
* **Задача:** Проверить гипотезу о том, что долгая доставка курьерами является главной причиной низких оценок (1-5 звезд).
* **Решение:** Рассчитал срок доставки в днях, применил коэффициент ранговой корреляции **Спирмена** [12.1].
* **Итог:** Коэффициент составил **-0.23** (p-value: 0.0). Связь подтвердилась, но она слабая. Логистика не является главным фактором плохих оценок.
